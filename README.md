# ASD-STE100 中文规则词表

ASD-STE100 简化技术英语的规则中文版。53 条规则，9 节，附改写示例。

英文原文来源：[ASD-STE100 Issue 9](https://www.asd-ste100.org/)（2025-01-15，官方免费下载）。
英文词表来源：[`simple-english`](https://hermes-agent.nousresearch.com/docs/user-guide/skills/optional/creative/creative-simple-english)（作者 AminBlg，MIT）。
本仓库是这两份材料的**中文改写**，不是官方文本，也不含官方词典。

## 用途

写中文技术文档的人按这份词表写字。读者疲倦时只能读一遍，每句话必须扛住这一遍。

规则也删掉 AI 文的常见痕迹：长句、同义词替换、含糊词、废话、装饰性从句。

## 两条使用边界

1. **本词表管风格，不管事实。** 改写时保留技术含义、不确定性、时间背景、测量的全部条件。
2. **代码、标识符、命令、报错原文、专有名词不动。** 即使它们违反词表。
